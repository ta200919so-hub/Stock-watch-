# Stock Watch AI v2

## 主な更新
- 証券コード / ティッカーの手入力を廃止
- 銘柄名検索 → 候補選択で内部シンボルを自動設定
- 購入単価・保有株数を登録
- 投資額・現在評価額・含み損益を自動計算
- ポートフォリオ全体の投資総額・評価額・損益を表示
- 日本株 / 米国株の現在株価を取得
- 米国株は USD/JPY で円換算
- Service Worker を v2 化し更新反映を改善

## Vercel
このフォルダの中身をリポジトリのルートに置いてください。
`api/search.js` と `api/quote.js` は Vercel Functions として動作します。

## 注意
マーケットデータは公開エンドポイントを利用するため、遅延・仕様変更・一時停止の可能性があります。
本番運用で安定性が必要になったら正式なマーケットデータAPIへ切り替えてください。
