# Stock Watch AI v1

iPhoneのホーム画面に追加できるPWAです。

## 公開方法（Vercel / Netlify / GitHub Pagesなど）
このフォルダの中身を静的サイトとして公開してください。

## iPhoneへの追加
1. 公開URLをSafariで開く
2. 共有ボタン
3. 「ホーム画面に追加」
4. 「追加」

## 現在できること
- 日本株・米国株の登録
- すべて日本円表示
- 登録時からの騰落率
- ウォッチリストを端末内に保存
- 簡易AI風コメント
- PWAとしてホーム画面追加・オフライン起動

## 次に必要なもの
実株価・USD/JPY・ニュース・決算・生成AIを自動取得するには外部APIとサーバー側処理を追加してください。
APIキーはブラウザ側の app.js に直接書かないでください。
